# Пользовательские звуки (Custom Sounds)

Любой `.ogg` или `.wav` файл, положенный в эту папку с соответствующим именем, автоматически заменяет звук в игре:

| Имя файла | Описание события |
|---|---|
| `campfire_real.ogg` | Фоновый бесконечный треск костра (уже встроен!) |
| `lighter_real.ogg` | Щелчок кремня и вспышка пламени зажигалки (уже встроен!) |
| `match_scratch.ogg` | Трение спички о коробок |
| `match_light.ogg` | Воспламенение спички / вспышка растопки |
| `match_break.ogg` | Хруст сломанной спички |
| `flint_clink.ogg` | Удар стали о кремень |
| `wood_drop.ogg` | Стук подбрасываемого дерева |
| `blow.ogg` | Выдох / раздувание углей |
| `steam_hiss.ogg` | Шипение пара при дожде на угли |
| `poker_poke.ogg` | Ворошение углей кочергой |
| `night_forest.ogg` | Фоновые сверчки и ночной лес |
